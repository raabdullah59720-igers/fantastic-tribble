TERRAVEX APEX — FULL EARTH SCIENCE UPGRADE / QUICK INSTALL

1) Download the FULL ZIP and extract it.
2) In the extracted folder, select every file plus the assets folder.
3) Upload the contents to the ROOT of your GitHub repository (repository name: terravex-apex). Do not upload only the ZIP; do not add another nested folder.
4) Keep the local CSS/JS files beside index.html and keep all images inside assets/.
5) GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
6) Open your GitHub Pages URL. Test Earthquake Monitor, Seismic & Plate Motion, Earth Observation, Thunderstorm Energy Recovery, and Alert Center.

IMPORTANT:
- Back up the old repository before replacing files.
- USGS feed = reported earthquakes, not earthquake predictions. First good fetch is the baseline.
- NASA GIBS imagery is date-based and may be delayed/incomplete. It is not video-live.
- Bangladesh Satellite-1 (BS-1) is a communications/broadcasting satellite in the public BSCL service description; this package does not pretend to read an Earth-imaging feed from it.
- Weather-model storm risk is not a lightning detector or official warning. Browser notifications require a user click and permission.
- Tectonic motion animation is an exaggerated time-lapse. Its scenario rates are not live GNSS measurements.
- Never connect any experimental energy-storage circuit to a lightning protection conductor or real lightning path.
